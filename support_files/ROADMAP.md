## Requirements by Gate

### GATE 0 — Enrolment (mandatory for everyone)

- Must master typing **before any class**. Use a Linux typing trainer (Klavaro, Tux Typing) or browser-based trainer.
- Measurable bar: **25+ WPM at 95% accuracy, three consecutive tests.**
- Why: the terminal, Calc, and Python all slow down learners who cannot type. This gate raises completion rates dramatically.
- No typing master → no enrolment. No exceptions.

### TIER 1 — Digital Independence (the mandatory doorway)

- The existing 10-episode series. Linux, terminal, first Bash script.
- Exit requirement: **assessment** = quiz + Episode 9 script deliverable + Episode 10 GitHub repo publicly published.
- Successful learners become "Digital Independence certified."
- **Nobody enters Track A *or* Track B without this certificate.** This is the prerequisite floor — it stays strict.

### TRACK A — Office Productivity (LibreOffice)

- Order: **Calc (10 sessions) → Writer (6 sessions) → Impress (4 sessions).** Data first — every report starts as a table.
- Careers: administration, data entry, NGO reporting, teaching materials.
- Track A graduates may later join Track B if they also hold the Tier 1 certificate. Calc is a bonus, not a requirement, for entering GIS.

### TRACK B — Geospatial Career (GIS & Automation)

Dependency order — each module requires the previous one:

1. **GIS & QGIS Beginners (10 weeks)** — requires Tier 1 certificate. Coordinate systems, vector/raster, map layouts, data capture.
2. **QGIS Advanced (4 weeks)** — requires the completed 10-week beginner course. No mid-way entry.
3. **Python for GIS** — requires QGIS Advanced. Spreadsheet (Calc) thinking is a recommended co-requisite for attribute-table work.
4. **PyQGIS automation** — requires Python for GIS. Script and batch geospatial processing.
5. **AI for geospatial analytics + dashboards** — last stage; builds on PyQGIS output and assumes data literacy.
6. **Web mapping (Folium / Leaflet)** — the capstone for sharing interactive maps with decision makers.

### Keep the branches open (follow your dreams)

- Both tracks exit into the same pool.
- A learner may either apply Office skills in community/NGO work, or continue up the GIS/Python ladder.
- Certificates let learners choose later — no dead ends.

> "No learner may register for any course without first passing the Typing Gate (25 WPM @ 95%). All learners must hold the Digital Independence certificate before enrolling in either the Office or Geospatial tracks. QGIS Advanced, Python, and AI modules require completion of the preceding required module."

## The Five Non-Negotiables

1. Typing gate before enrolment.
2. Digital Independence certificate before any track.
3. Free forever, open source.
4. Old hardware (2-4 GB RAM) is the target.
5. Sudanese context, simple English.
