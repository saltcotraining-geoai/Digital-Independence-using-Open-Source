# Quiz — Episode 3 · Part 1: Ventoy & MX Linux Live USB
**10 questions — with proposed answers**

---

### 1. What is Ventoy?
- A) A Linux distribution
- B) A tool that makes one USB able to boot many ISOs
- C) An antivirus
- **Answer: B** — Copy ISOs to the Ventoy USB and pick at boot.

### 2. What does “live USB” mean?
- A) Linux runs from the USB without touching your hard drive — safe to try
- B) It permanently replaces Windows as soon as you plug it in
- C) It needs internet to work
- **Answer: A** — Nothing is installed until you run the installer in Part 2.

### 3. How big should the USB be?
- A) 8 GB minimum, 16 GB recommended
- B) 1 GB is enough
- C) 100 GB
- **Answer: A** — Fits MX ISO and leaves room for persistence/Mint later.

### 4. Which key do you usually press to open the boot menu?
- A) F12 / ESC / F8 / DEL (depends on laptop)
- B) Only the Space bar
- C) No key — it boots automatically
- **Answer: A** — Tap repeatedly right after power-on.

### 5. You see the MX desktop from the USB. Are your Windows files already erased?
- A) Yes
- B) No — live mode leaves the hard drive untouched
- C) Only photos are erased
- **Answer: B** — Install only happens in Part 2 when you click “Use Entire Disk” and confirm.

### 6. What is the main advantage of Ventoy over Etcher/Rufus for this course?
- A) It is the only way to install Linux
- B) You can keep multiple ISOs (MX, Mint, etc.) on one USB and choose at boot
- C) It is faster to download
- **Answer: B** — One USB for the whole Episode 3 trilogy.

### 7. If your laptop does not boot from USB, what should you check first?
- A) Try another USB port, re-enter boot menu, ensure Secure Boot is disabled if needed
- B) Buy a new laptop immediately
- C) Format your hard drive
- **Answer: A** — Most live-boot issues are boot-key or port related.

### 8. What does “persistence” mean on a Ventoy USB (optional)?
- A) Your live session saves files/settings on the USB between reboots
- B) It makes the USB read-only forever
- C) It installs Linux permanently
- **Answer: A** — Useful for trying without installing.

### 9. Which OS are we trying live in Part 1?
- A) MX Linux
- B) Windows 11
- C) macOS
- **Answer: A** — MX XFCE — lightweight for 2–4 GB RAM.

### 10. After trying live, what is the next step in the series?
- A) Part 2 — Install MX Linux permanently (Replace Windows)
- B) Directly to Episode 10
- C) Stop using the USB
- **Answer: A** — Only after you have backed up.

**Scoring:** 8+/10 = ready for Part 2.
