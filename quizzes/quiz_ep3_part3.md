# Quiz — Episode 3 · Part 3: Try Linux Mint (Distro Hopping)
**10 questions to check understanding — with proposed answers for review**

*Use after watching `ep3_part3_LM_installation_ALTERED.mp4` (22:21). Each question has one correct answer.*

---

### 1. What does “distro hopping” mean?
- A) Updating the same Linux to a newer version
- B) Trying a different Linux distribution on the same computer
- C) Installing Linux alongside Windows
- **Answer: B** — Installing a different distro (here Mint instead of MX) on the same machine. You already know the steps from Part 2.

### 2. Why is Linux Mint also a good choice for a 2–4 GB RAM laptop?
- A) It needs 16 GB RAM minimum
- B) It is lightweight, Windows-like, and runs well on old hardware — like MX
- C) It only works on new gaming laptops
- **Answer: B** — Mint Cinnamon/Xfce is also light and familiar for Windows users.

### 3. What do you need before you start Part 3?
- A) A new computer
- B) The same Ventoy USB from Part 1, now with both MX and Mint ISOs on it
- C) A paid license
- **Answer: B** — Ventoy can hold many ISOs; you pick Mint at boot time.

### 4. What does “Use Entire Disk” do in the Mint installer?
- A) Keeps Windows and adds Mint beside it
- B) Erases the whole drive and sets it up automatically for Mint — no manual partitioning
- C) Only erases your Documents folder
- **Answer: B** — Same easy button as MX. It is the point of no return.

### 5. Do you need to back up again if you already backed up before Part 2?
- A) No, the old backup is always enough
- B) Yes — if you added any new files, photos, or browser bookmarks in MX, back them up again
- C) Backup is never needed
- **Answer: B** — Part 3 erases the MX install too.

### 6. How long does the copy/install step usually take?
- A) 2–3 hours
- B) 5–10 minutes (depends on disk speed)
- C) 30 seconds
- **Answer: B** — Progress bar for copying files + installing GRUB, just like Part 2.

### 7. What is the main practical difference between MX Linux and Linux Mint for a beginner?
- A) Completely different install steps
- B) Mostly the desktop look and preinstalled apps — the installer steps are almost identical
- C) Mint requires terminal commands, MX does not
- **Answer: B** — Both are Debian/Ubuntu-based, both use a graphical “Use Entire Disk” wizard.

### 8. What should you do on first boot into Mint?
- A) Immediately try another distro
- B) Connect to Wi-Fi, run Update Manager, explore the menu
- C) Throw away the Ventoy USB
- **Answer: B** — Get online and update — same as after MX.

### 9. Can this method keep both MX and Mint at the same time?
- A) Yes — “Use Entire Disk” keeps both
- B) No — it replaces the entire drive with Mint. Dual-boot needs manual partitioning (not covered here)
- C) Yes, automatically
- **Answer: B** — This course teaches the simple “replace” method.

### 10. If the installer does not see your USB or the screen looks different, what is the best first step?
- A) Give up
- B) Reboot, try the boot key again (F12/ESC/F8/DEL), try another USB port, and check the troubleshooting guide / ask in comments with your laptop model
- C) Buy a new laptop
- **Answer: B** — Most issues are boot-key or USB-port related.
