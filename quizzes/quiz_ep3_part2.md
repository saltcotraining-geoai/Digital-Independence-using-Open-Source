# Quiz — Episode 3 · Part 2: Install MX Linux (Replace Windows)
**10 questions — with proposed answers (22:32)**

---

### 1. What is the single biggest risk in this episode?
- A) Erasing the entire drive if you proceed without a backup
- B) The live USB expiring
- C) Needing to buy a new mouse
- **Answer: A** — “Use Entire Disk” erases everything; back up first.

### 2. What must you back up before clicking Install?
- A) Emails, photos, bookmarks, school projects — anything you want to keep
- B) Nothing
- C) Only the Windows wallpaper
- **Answer: A** — After install you cannot recover them.

### 3. Where is the MX Installer on the live desktop?
- A) An icon on the desktop labeled “MX Installer”
- B) Hidden in the BIOS
- C) On a website only
- **Answer: A** — Double-click it — no terminal needed.

### 4. What does “Use Entire Disk” mean?
- A) Keep Windows and add Linux beside it
- B) Erase the whole drive and let the installer partition automatically
- C) Only use 1 GB of the drive
- **Answer: B** — The easy, automatic option taught in the video (6:00).

### 5. Do you need to manually create swap or partitions?
- A) Yes, you must type commands
- B) No — the installer creates swap and file system for you
- C) Only on 2 GB RAM machines
- **Answer: B** — Explained at 14:00; swap helps low-RAM laptops.

### 6. What information does the installer ask for your user account?
- A) Full name, username (one word, lowercase), password, computer name
- B) Credit card
- C) Only your age
- **Answer: A** — At 8:00/10:00; password is needed for updates and admin tasks.

### 7. How long does the copy/install usually take?
- A) 5–10 minutes depending on disk speed
- B) 2 hours
- C) 10 seconds
- **Answer: A** — Progress bar for formatting/copying + GRUB (10:00–18:00).

### 8. What do you do when the installer says “Installation Complete”?
- A) Pull out the USB when told, press Enter, let it reboot from the hard drive
- B) Keep the USB in forever
- C) Turn off the power immediately
- **Answer: A** — First boot is at 20:00.

### 9. On first boot, what should you do?
- A) Connect Wi-Fi, run updates, explore the menu
- B) Reinstall Windows immediately
- C) Nothing — the system is already fully updated
- **Answer: A** — At 20:00 — get online and update.

### 10. If the screen shows a different partitioning layout than the video, what is the best move?
- A) Stop, take a photo, compare with the “Use Entire Disk” screen at 6:00, and ask in comments with your laptop model
- B) Click randomly
- C) Ignore the warning dialog
- **Answer: A** — Every disk is slightly different; asking with details gets the best help.

**Scoring:** 8+/10 = ready for Part 3 (Mint distro-hop).
