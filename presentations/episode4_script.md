# Episode 4 — Make Yourself at Home
**Duration:** 22 minutes
**Target:** Absolute beginners, Sudanese communities, 2-4 GB RAM laptops
**Approach:** GUI only. Desktop tour. Software Manager.
**Instructor:** Saltibin

---

## 0:00-2:00 — Hook

### Visual
Show the fresh MX Linux desktop. Move the mouse around the interface slowly.

### Script
"Salam aleikum. You have Linux installed. Now let's make it feel like home.

Today: no terminal. All mouse. We customize the desktop, connect to WiFi, and install the applications you actually need — LibreOffice, VLC, Firefox. All from a safe, virus-free app store.

By the end of this episode, your Linux machine will be a fully functional workstation."

---

## 2:00-6:00 — Desktop Tour

### Visual
Point at each part of the desktop. Open the Application Menu. Open the file manager. Open system settings.

### Script
"Let's start with a tour of your new desktop.

Bottom-left corner: click the MX Linux logo. This is the Application Menu — like the Start button in Windows. It's organized into categories: Office, Internet, Graphics, System. All your applications live here.

Bottom-right corner: the system tray. Speaker icon for volume. Network icon for WiFi. Battery icon if you're on a laptop.

Right-click anywhere on the empty desktop. Select 'Desktop Settings'. You can change your wallpaper, icon size, and theme here. Pick something that makes you happy.

The file manager icon is on the taskbar — click it. This is like Windows Explorer. Your folders are here: Documents, Downloads, Music, Pictures. All your files, organized the same way you're used to."

---

## 6:00-10:00 — WiFi & System Settings

### Visual
Click the network icon. Select a WiFi network. Type password. Show it connects.

### Script
"Click the network icon in the system tray. You'll see a list of available WiFi networks. Click yours, type the password, and click Connect.

Your computer remembers this network forever. Next time you turn it on, it connects automatically.

For our Sudanese audience: if your WiFi uses a proxy or requires a login page (captive portal), open Firefox first — it will redirect you to the login page automatically.

Open the Settings panel from the menu. Here you can adjust display resolution, power settings, printers, and user accounts. Everything is graphical. Everything is accessible."

---

## 10:00-16:00 — Installing Applications

### Visual
Open Software Manager. Search for LibreOffice. Click Install. Search for VLC. Install. Search for Chrome or Brave. Install.

### Script
"Now for the best part — installing software.

Open the Application Menu and look for 'Software Manager' or 'MX Package Installer'. Click it.

This is your virus-free app store. Every application here has been tested and verified by the Linux community. No fake download buttons. No malware. No ads.

Type 'LibreOffice' in the search bar. Click the result. Click the green Install button. Enter your password. It downloads and installs automatically.

Do the same for VLC Media Player — plays any video or music file.

Do the same for Firefox — or Brave Browser if you prefer something more privacy-focused.

Everything you install from here is free, open source, and automatically updated."

---

## 16:00-20:00 — MX Tools

### Visual
Open MX Tools from the menu. Show Driver Manager, Display settings, System Info.

### Script
"MX Linux comes with a unique set of tools called MX Tools. Open them from the menu.

Here you'll find:
- Driver Manager: if your WiFi or graphics card isn't working, check here for proprietary drivers.
- Display: adjust screen resolution if things look too big or too small.
- MX Cleanup: removes old files to free up disk space.
- System Info: shows your hardware details — processor, RAM, storage.

These tools make MX Linux special. They give you control over your system without needing to touch the terminal."

---

### Visual
Show the desktop with newly installed applications. Summary screen. Credits.

### Script
