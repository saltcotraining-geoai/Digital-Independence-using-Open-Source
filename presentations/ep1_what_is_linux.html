Windows 11 requires 4GB minimum — and even that is painful

What is Linux?

  • An operating system — like Windows or macOS
  • Free — costs zero dollars
  • Open source — anyone can see the code
  • Lightweight — runs on old hardware
  • Secure — far fewer viruses
  • Powers most of the internet (servers, Android, cloud)

Why Switch?

✅ Faster

Linux breathes life into old 2GB-4GB machines

✅ Free

No license fees. No "upgrade to Windows 11" pop-ups.

✅ No Viruses

Permission system stops malware. No antivirus needed.

✅ No Spying

No telemetry. No ads in your start menu.

Common Fears — Debunked

❌ "I need the terminal"

Not true. Modern Linux works with mouse & clicks. Terminal comes later.

❌ "My apps won't work"

LibreOffice, Firefox, Chrome, VLC, Zoom — all available.

❌ "It's for hackers"

Linux is for everyone. It's just a different operating system.

❌ "I'll lose my files"

We start with a LIVE USB — zero risk to your data.
