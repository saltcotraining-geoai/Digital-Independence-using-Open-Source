EPISODE 8

The Master Key

The Master Key & Security System

What keeps Linux virus-free — explained simply

Permission Denied = GOOD

Try reading a system file:

student@mx:~$ cat /etc/shadow
Permission denied

Linux blocked you. That's security working!

🔒 "Permission denied" = Linux protecting itself

sudo = Master Key

sudo = SuperUser DO

Temporary admin access — one command at a time

student@mx:~$ sudo cat /etc/shadow
[sudo] password for student: (nothing shows — normal!)
🔑 sudo = "I have permission to change this one thing"

The sudo Warning

⚠️ READ sudo COMMANDS BEFORE RUNNING THEM

If a stranger online says:
sudo rm -rf /
That erases YOUR ENTIRE COMPUTER

✅ Rule: Know what a command does before you sudo it

ls -l — See Permissions

student@mx:~$ cd /home/student
student@mx:~$ ls -l
-rw-r--r-- 1 student student 1024 Jul 26 homework.txt

The first column = permission code:
- rw- r-- r--

Decoding the Permission Code

-rw-r--r--

Owner (You)

rw-

Read + Write
Can view and edit

Group

r--

Read only
Can view, cannot edit

Others

r--

Read only
Everyone else

What About "x"?

x = Execute = "Can this file run as a program?"

📄 Normal file

-rw-r--r--

Can read & write
⛔ Cannot execute

⚡ Executable file

-rwxr-xr-x

Can read, write, AND run
✅ Can execute as program

chmod +x — Make It Runnable

chmod +x = Add Execute Permission

Create a script → Try to run → Fail → Fix it:

student@mx:~$ nano hello.sh
(type: #!/bin/bash
echo "Hello Linux!")
student@mx:~$ ./hello.sh
bash: ./hello.sh: Permission denied
student@mx:~$ chmod +x hello.sh
student@mx:~$ ./hello.sh
Hello Linux! ✅

Why Linux is Safer

🪟 Windows

New files can run automatically
Malware can execute by itself
User gets no warning

🐧 Linux

New files are PASIVE by default
You must EXPLICITLY allow execution
chmod +x = "I trust this file"
