EPISODE 5

The Terminal is Not Scary

pwd • ls • cd

The terminal is just a text-based file manager — nothing to fear!

Terminal = Text File Manager

🖱️ File Manager

Click folders to open them
See files as icons

⌨️ Terminal

Type folder names to go there
See files as text list

Same result. Different method.

Open the Terminal

Ctrl + Alt + T

Or click the black icon in the bottom panel

📁 File Manager

Home
├─ Desktop
├─ Documents
├─ Downloads
├─ Music
└─ Pictures

student@mx:~$

Waiting for command...

pwd — Where Am I?

pwd = Print Working Directory

"Where am I standing right now?"

student@mx:~$ pwd
/home/student

Your terminal shows the exact folder path — just like the file manager bar

ls — What's Here?

ls = List Files

"What files are in this folder?"

student@mx:~$ ls
Desktop Documents Downloads Music Pictures

Look at your file manager — same folders!

ls -a — Hidden Files

ls -a = Show ALL Files

Files starting with . are hidden
Terminal shows you EVERYTHING

student@mx:~$ ls -a
. .. .bashrc .profile Desktop Documents Downloads Music Pictures

cd — Go To...

cd = Change Directory

"Go to a different folder"

student@mx:~$ cd Desktop
student@mx:~/Desktop$

Watch your file manager jump to Desktop!

cd .. — Go Back

cd .. = Go UP one folder
(. . = parent directory)
student@mx:~/Desktop$ cd ..
student@mx:~$

Back to Home. See the prompt changed?

Practice Session

Try this sequence:

pwd
ls
cd Documents
pwd
ls
cd ..
cd Downloads
pwd

You're navigating Linux faster than most Windows users already!

✅ Episode 5 Summary

  • pwd = Where am I?
  • ls = What's here?
  • ls -a = Show everything (even hidden)
  • cd = Go to a folder
  • cd .. = Go back one level
