EPISODE 2

Try Before You Install

Zero Risk — Your Windows Files Stay Safe

Press → or Space for next slide

What You Need

  • Any computer (2GB RAM or more)
  • 8GB+ USB flash drive
  • Internet connection (for downloading)
  • 10 minutes of your time
⚠️ USB WILL BE ERASED — Back up your files first

Step 1: Download MX Linux

MX Linux XFCE

Lightweight • Beginner-friendly • Runs on 2GB-4GB RAM

mxlinux.org → Downloads → XFCE

File Size

About 2GB

Download while you prepare the USB tool

Step 2: Get Ventoy

ventoy.net → Download → Windows ZIP

Extract the ZIP file

Run Ventoy2Disk.exe

Select your USB drive

Click Install (takes 10 seconds)

⚠️ THIS FORMATS THE USB — Double-check you picked the right drive

Step 3: Copy ISO File

DRAG & DROP ✅

After Ventoy installs, your USB is named "Ventoy"

Just copy-paste the MX Linux ISO file into it

Like copying a normal document — no special tools needed

Step 4: Boot from USB

Spam the key at startup!

F12

Dell • Lenovo • Gigabyte

F9

HP

ESC

ASUS • Acer

F11

MSI • AsRock

Select your USB → Press Enter → Pick MX Linux from Ventoy menu

Step 5: Select "Try" NOT "Install"

✅ Choose "Start MX Linux" or "Try Mode"
⛔ DO NOT click "Install" yet — you're just testing!

The WOW Moment

Open Terminal → Type:
free -h

Linux running on ~500MB RAM

Windows 10 would use ~3GB

You just freed 2.5GB of memory!

Everything is Safe

🔒 Your Windows files are UNTOUCHED

▸ Linux runs entirely in your computer's RAM

▸ Your hard drive is not modified

▸ Remove USB → Restart → Back to Windows exactly as before

⚠️ Still don't click "Install" — explore the desktop only

✅ Episode 2 Summary

  • Booted into Linux — zero risk to Windows
