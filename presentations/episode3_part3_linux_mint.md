# Episode 3 · Part 3 — Try Linux Mint (Distro Hopping)
**Series position:** Episode 3, Part 3 of 3
**Duration:** 20 minutes (target)
**Target:** Absolute beginners, Sudanese communities, 2-4 GB RAM laptops
**Approach:** GUI only. No terminal. Distro hopping made safe.
**Instructor:** Saltibin

---

## 0:00-2:00 — Hook

### Visual
Hold up the Ventoy USB. Show MX Linux desktop, then show Linux Mint logo next to it.

### Script
"Salam aleikum. In Part 1, you tried MX Linux live. In Part 2, you installed it permanently and replaced Windows. Now — the question many students ask me: 'Once I have a Linux system, am I stuck with it?'

The answer is a proud NO. Today, Part 3, I'll show you the superpower of the open source world: distro hopping. We'll take the very same Ventoy USB, add Linux Mint — a close cousin of MX Linux — and install it, replacing MX Linux completely.

If you can go from Windows to MX, and then from MX to Mint, no operating system will ever feel scary again."

---

## 2:00-5:00 — Why You Can Hop Freely

### Visual
Show a line of distro logos: MX Linux → Linux Mint → antiX → Debian. Same USB, same ventoy.

### Script
"Here is the beautiful thing: one Ventoy USB can hold many distros at the same time. We don't re-flash anything — we just copy an ISO file, like copying a document.

MX Linux and Linux Mint are both built on the same family tree — Debian. Their desktops look and feel very similar. That is exactly why hopping is so easy: your knowledge carries over. The start menu, the software store, the settings — everything is in almost the same place.

So trying Mint is not a scary experiment. It is just choosing a different flavor of the same great world."

---

## 5:00-8:00 — Adding Linux Mint to the USB

### Visual
Open browser. Go to linuxmint.com → Download → pick XFCE edition. Download ~2GB. Drag the ISO into the Ventoy USB.

### Script
"Open your browser and go to linuxmint.com.

Click Download. Choose the XFCE edition — lightweight, and it runs great on 2-4 GB RAM machines, just like MX Linux. The file is about 2 gigabytes. When the download finishes, open your Ventoy USB and simply drag the ISO file in, next to your MX Linux ISO.

Close the USB safely and restart the computer. Tap your boot key — F12 for Dell and Lenovo, F9 for HP, ESC for ASUS — and select your USB. Ventoy now shows you a menu with both MX Linux and Linux Mint. Just like a restaurant menu, you pick what you want to eat today."

---

## 8:00-12:00 — The Mint Live Session

### Visual
Select Linux Mint in the Ventoy menu. Boot into the Live desktop. Open menu, show Software Manager, show file manager.

### Script
"Pick Linux Mint and press Enter. In a moment, you land on the Mint desktop — bright, fresh, and familiar. This is the live session, running entirely from the USB. Your MX Linux installation on the hard drive is completely untouched, asleep.

Explore the desktop. Open the start menu in the corner. Notice how similar it is to MX Linux — a menu, a taskbar, a file manager. Open the Software Manager and search for the same apps you used in Episode 1: LibreOffice, VLC, Firefox. They're all there, one click away.

The point: Linux is Linux. The distro is just the packaging and the polish. Your skills travel with you."

---

## 12:00-17:00 — Replacing MX Linux with Mint

### Visual
Double-click Install Linux Mint icon. Click through: language, keyboard, "Erase disk and install". Ask for name/user/password. Show progress bar.

### Script
"Now let's do the part that feels bold: on the desktop, double-click 'Install Linux Mint'.

Walk through the same friendly screens you saw in Part 2 — choose your language, your keyboard, your time zone. Then the installer asks about disk setup. Select 'Erase disk and install Linux Mint'. Yes, it will replace MX Linux on this machine — that is exactly what we're demonstrating.

Click Continue, enter your name, username, and a password you'll remember, then click Install. The progress bar takes a few minutes. When it finishes, remove the USB and restart."

---

## 17:00-19:00 — First Boot on Mint

### Visual
Boot into Linux Mint from hard drive. Welcome screen. Show desktop, menu, Software Manager.

### Script
"Your computer restarts and boots straight into Linux Mint — installed permanently on your hard drive, replacing MX Linux.

Log in with the password you created. Take a look: a complete operating system, fresh and working. Open the menu, browse the settings, install an app from the Software Manager. You did it — Windows to MX, MX to Mint, and nothing broke. That is distro hopping in action, and it took us only a few minutes."

---

## 19:00-20:00 — Recap & Credits

### Visual
Summary screen. Then credits.

### Script
"Today you learned that choosing a Linux distro is not a lifetime commitment:

1. One Ventoy USB holds many distros
2. Adding Linux Mint was just a drag-and-drop of an ISO file
3. The Mint live session is safe — nothing changes on your disk
4. Installing Mint replaced MX Linux just as easily as MX replaced Windows

Your challenge: download one more ISO — antiX for very old 32-bit machines, or any distro that interests you — add it to the same USB, and try it live. No risk, no fear.

Try distros freely. That freedom is the whole point of open source.

Open source means you are never locked in. Thanks to the MX Linux team, the Linux Mint team, the Ventoy developers, the Debian project, and every developer who gives their work away for free.

I'm Saltibin. See you in the next episode."
