EPISODE 9

One Command to Rule Them All

From User → Creator

One command = Full system maintenance!

What is a Script?

📜 Script = Recipe = List of Commands in a File

Instead of typing commands one by one, you write them all in a file and run it once.

❌ Before

Type 4 commands
Wait between each
Remember each one
Takes 5 minutes

✅ After

Type ONE word
Script does all 4
Automatic
Takes 5 seconds

Writing the Script

Open terminal → Type:

student@mx:~$ nano maintenance.sh

(nano opens a blank file)

The Shebang Line

Line 1 — ALWAYS start with this:

#!/bin/bash

Translates to: "Read this file using the Bash interpreter"

Without this line, the computer won't know how to run your script

Adding Comments

# = Comment = Notes for Humans

Lines starting with # are ignored by the computer

#!/bin/bash
# This is my first script
# The computer ignores these lines
echo "Hello!"

Use # to label what each part of your code does

The Full Script

Type this into nano exactly:

#!/bin/bash
# System maintenance script
echo "=== Starting system update ==="
sudo apt update && sudo apt upgrade -y
echo "=== Cleaning old packages ==="
sudo apt autoremove -y
sudo apt clean
echo "=== Maintenance complete! ==="

Ctrl + X → Y → Enter to save

Making It Runnable

Remember chmod +x from Episode 8?

student@mx:~$ chmod +x maintenance.sh
✅ Now it's a program, not just a text file

Run It!

student@mx:~$ ./maintenance.sh
=== Starting system update ===
[apt downloads and installs updates]
=== Cleaning old packages ===
[old packages removed]
=== Maintenance complete! ===
⚡ ONE COMMAND = FULL SYSTEM MAINTENANCE

Desktop Shortcut Bonus

  • Right-click maintenance.sh in file manager
  • Click Properties
  • Go to Permissions tab
  • Check Execute
  • Now double-click the file to run it!
✅ Double-click = Run maintenance — no terminal typing needed

✅ Episode 9 Summary

  • #!/bin/bash = "Read this as code"
  • # = Comment (notes for humans)
  • echo = Print message on screen
  • Script + chmod +x = automated tool
  • ./filename.sh = Run your script
