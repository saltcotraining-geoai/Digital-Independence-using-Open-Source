EPISODE 7

Find Anything in Seconds

locate • grep • cp • mv

Terminal search uses ZERO memory — perfect for 2GB laptops!

The Problem

Opening the file manager's search bar on a 2GB laptop = freeze

🐌 Windows Search

Indexes your drive while you wait
Uses 500MB+ RAM
Takes minutes

⚡ Terminal Search

Uses a pre-built index
Uses ~1MB RAM
Takes 0.2 seconds

locate — Instant File Finder

locate = Find files by name instantly
student@mx:~$ locate homework
/home/student/School/Math/homework.txt

Uses a pre-built index = almost zero RAM

Install & Update locate

If "locate" not found:

student@mx:~$ sudo apt install mlocate
student@mx:~$ sudo updatedb

sudo updatedb = Builds the search index
Run it once after install

grep — Search Inside Files

grep = Find text INSIDE files

Your teacher sent 50 PDFs. Which one mentions "exam"?

student@mx:~$ cd ~/School
student@mx:~/School$ grep -r "exam" .
./English/notes.txt:Exam is next Tuesday!

locate vs grep

🔍 locate

Finds files BY NAME
locate homework
→ Finds the file

🔎 grep

Finds text INSIDE FILES
grep -r "exam" .
→ Finds the word

cp — Copy Files

cp = Copy files
student@mx:~$ cp homework.txt homework_backup.txt

Creates a duplicate of the file
Great for making backups before editing!

mv — Move or Rename

mv = Move OR Rename

Move a file:

student@mx:~$ mv homework.txt School/Math/

Rename a file (same folder, new name):

student@mx:~$ mv homework.txt math_notes.txt

Same command for both actions!

Why This Matters on Low RAM

  • locate = instant, uses ~1MB RAM
  • Windows Search = slow, uses ~500MB RAM
  • grep = find text in 100 files in 2 seconds
  • cp + mv = no dragging folders around
⚡ Your 2GB Linux searches faster than a 16GB Windows PC!

✅ Episode 7 Summary

  • locate = Find files by name (instant)
  • grep -r = Find text inside files
  • cp = Copy a file
  • mv = Move or rename a file
