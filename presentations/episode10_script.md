## 10:00-15:00 — Building Your GitHub Portfolio

### Visual
Go to github.com. Create an account. Create a repository. Upload maintenance.sh. Commit.

### Script
"Go to github.com and create a free account.

Click the '+' icon in the top right → 'New repository.'

Name it: linux-automation-scripts. Leave it public. Click 'Create repository.'

Click 'Upload files.' Open your file manager, find maintenance.sh from Episode 9, and drag it into the browser window.

Scroll down. Type a short message: 'Initial commit — system maintenance script.' Click 'Commit changes.'

You now have a public portfolio. When an employer asks 'What Linux experience do you have?' — you send them this link.

You can add your diagnostic dashboard from the bonus section, your backup script, any tools you build. Every script proves your skills."

---

## 15:00-19:00 — The Linux Family

### Visual
Show logos of different distros. Explain where each one fits.

### Script
"You learned on MX Linux. That's an excellent starting point. But Linux is a family.

Ubuntu — the most popular. Best community support. Great for beginners.
Linux Mint — looks most like Windows. Easiest transition for newcomers.
Debian — what MX Linux is built on. Rock solid. Runs most of the internet.
Fedora — cutting edge. Used by professional developers.
antiX — for 32-bit machines and 2GB RAM. Even lighter than MX.

The commands are the same across all of them. pwd, ls, cd, chmod, sudo, apt — identical. Once you know one Linux, you know them all."

---

## 19:00-21:00 — What to Learn Next

### Visual
Show a roadmap: Git, Networking, Certifications.

### Script
"To go further, focus on three things:

First: Git. Learn to track changes to your scripts and collaborate with others. It's the standard tool used by every tech company.

Second: Basic networking. Learn IP addresses, SSH, and how to connect to remote servers. This is essential for system administration.

Third: Certifications. CompTIA Linux+ and LPIC-1 are industry-recognized. Search for free study guides online.

Most importantly: use Linux every day. The more you use it, the more natural it becomes."
