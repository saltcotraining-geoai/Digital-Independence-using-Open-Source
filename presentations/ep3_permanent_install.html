EPISODE 3

Make It Yours

Moving Linux to Your Hard Drive

⚠️ THIS ERASES THE DRIVE — Back up your files first!

What You Need

  • Your Ventoy USB from Episode 2
  • A computer to install on
  • All important files backed up
  • 10-15 minutes of install time
⚠️ If you share this computer with family — stop. We'll cover dual boot later.

Boot from USB

Same process as Episode 2:

  • Plug in Ventoy USB
  • Restart → Spam boot key (F12/F9/ESC)
  • Select USB → Pick MX Linux
  • Wait for desktop to load
This time, we WILL click "Install"

  • Click Finish
