EPISODE 6

Create Like a Pro

mkdir • touch • nano • rm

Terminal = Faster File Manager

mkdir — Make Folders

mkdir = Make Directory = New Folder
student@mx:~$ mkdir School
student@mx:~$ mkdir School/Math School/Science School/English

3 folders in one line!
Try doing that with right-click → New Folder

touch — Create Files

touch = Create empty file
student@mx:~$ cd School/Math
student@mx:~/School/Math$ touch homework.txt

Look in the file manager — a blank file appeared!

nano — Edit Text

nano = Simple text editor (inside terminal)
student@mx:~/School/Math$ nano homework.txt

Type your text → Ctrl + X to exit
→ Y to save → Enter to confirm

Open the file in file manager to see your text

rm — DELETE (⚠️ WARNING)

⚠️ rm = NO TRASH BIN
DELETED FOREVER

On Windows: Delete → Recycle Bin (can undo)
On Terminal: rm → GONE FOREVER

Safe Delete

rm -i = Ask before deleting
student@mx:~$ rm -i homework.txt
rm: remove regular file 'homework.txt'? y

The -i flag = "interactive"
Linux asks "Are you sure?" before each delete

✅ Use rm -i until you're comfortable!

Important Rule

  • Terminal has NO undo button
  • No Trash Bin to recover from
  • No "Are you sure?" pop-up (unless you use -i)
  • Always double-check before pressing Enter
When in doubt — add -i !

Your Workflow

mkdir Projects
cd Projects
mkdir Week1 Week2 Week3
touch notes.txt
nano notes.txt
# Type something → Ctrl+X → Y → Enter
ls -l
rm -i notes.txt

Practice this sequence until it feels natural

Better than GUI?

🖱️ GUI Way

Right-click → New Folder
Type "Week1" → Enter
Repeat 4 more times
= 15 clicks, 30 seconds

⌨️ Terminal Way

mkdir Week1 Week2 Week3 Week4 Week5
= 1 line, 2 seconds

✅ Episode 6 Summary

  • mkdir = Make folder
  • touch = Create empty file
  • nano = Edit text in terminal
  • rm = Delete (⚠️ permanent!)
  • rm -i = Safe delete
