EPISODE 3 · PART 3

Try Linux Mint

Distro Hopping Made Easy

MX → Mint → any distro you like. No fear.

Why You Can Switch Freely

▸ One Ventoy USB holds many distros at once

▸ No re-flashing — just copy an ISO file like a document

▸ MX Linux & Linux Mint are both Debian-based — very similar

▸ Your skills carry over: menu, software store, settings

Choosing a distro is NOT a lifetime commitment

Add Linux Mint to the USB

Download

linuxmint.com → Download → XFCE edition (~2GB)

Drag & Drop

Copy the Mint ISO into your Ventoy USB, next to MX Linux

Two distros, one USB — like a menu 🍽️

Boot and Choose

▸ Plug in USB → Restart → Spam boot key (F12/F9/ESC)

▸ Ventoy menu now shows MX Linux AND Linux Mint

▸ Pick Linux Mint and press Enter

Your MX installation is untouched — this is the LIVE session

The Mint Live Desktop

▸ Running entirely from the USB — your hard drive is safe

▸ Bright, fresh, familiar desktop

▸ Start menu, taskbar, file manager — just like MX Linux

Linux is Linux — the distro is just the packaging and polish

Everything Looks Familiar

Software Manager 🛒

▸ Search LibreOffice, VLC, Firefox — one click away

▸ Same apps you used in Episode 1

▸ Same look, same feel, same freedom

Replace MX with Mint

▸ Double-click Install Linux Mint

▸ Same friendly screens: language, keyboard, time zone

▸ Select "Erase disk and install Linux Mint"

⚠️ Yes — Mint replaces MX on this machine, exactly as MX replaced Windows

Install & Restart

  • Enter name, username, password
  • Click Install → progress bar (a few minutes)
  • When it finishes → remove USB → restart
✅ Mint boots from your hard drive — MX is gone

Welcome to Linux Mint

Log in with your new password

Open the menu — browse settings — install an app

Windows → MX → Mint. Nothing broke. 🤝

✅ Ep 3 · Part 3 Summary
