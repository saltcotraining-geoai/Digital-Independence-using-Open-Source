🚪 Gate by Gate — No Shortcuts

  • Gate 0: Master typing before any class — 25+ WPM @ 95%, 3 runs
  • Tier 1: Digital Independence certificate — quiz + script + public GitHub
  • Track A or B: requires the Tier 1 certificate, no exceptions
  • Track B ladder: each module needs the one before it — no mid-way entry
  • Branches stay open: certificates let students follow their dreams later
